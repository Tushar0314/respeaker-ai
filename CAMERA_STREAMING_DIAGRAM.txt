                               DATA FLOW
═══════════════════════════════════════════════════════════════════════════

1️⃣  CAMERA CAPTURES
    📷 Camera Module 3
    ↓
    Raw sensor data (12MP)
    ↓
    Resized to 1920×1080

2️⃣  ENCODING
    🔄 JPEG Encoder (Hardware)
    ↓
    Compressed JPEG (~100-200 KB per frame)
    ↓
    30 frames per second

3️⃣  STREAMING
    📡 HTTP Server (MJPEG)
    ↓
    Continuous stream of JPEG frames
    ↓
    Multipart/x-mixed-replace

4️⃣  VIEWING
    🌐 Web Browser
    ↓
    Decodes JPEG frames
    ↓
    Displays as video

                           SETUP WORKFLOW

ON RASPBERRY PI:

Step 1: Transfer Files
┌────────────────────────────────────────────────────────────────┐
│ scp camera_stream.py pi@raspberrypi.local:~/respeaker-ai/     │
│ scp camera_stream_auto.py pi@raspberrypi.local:~/respeaker-ai/│
│ scp setup_camera.sh pi@raspberrypi.local:~/respeaker-ai/      │
└────────────────────────────────────────────────────────────────┘

Step 2: Run Setup
┌────────────────────────────────────────────────────────────────┐
│ ssh pi@raspberrypi.local                                       │
│ cd ~/respeaker-ai                                              │
│ chmod +x setup_camera.sh                                       │
│ ./setup_camera.sh                                              │
└────────────────────────────────────────────────────────────────┘

Step 3: Start Streaming
┌────────────────────────────────────────────────────────────────┐
│ python3 camera_stream.py                                       │
│ # Choose option 1: Start HTTP Stream                           │
└────────────────────────────────────────────────────────────────┘

Step 4: View Stream
┌────────────────────────────────────────────────────────────────┐
│ Open browser on phone/computer:                                │
│ http://192.168.1.XXX:8080/                                     │
│ (Replace XXX with Pi's IP address)                             │
└────────────────────────────────────────────────────────────────┘

🚢 SCENARIO: Sailing with live camera feed

SETUP:
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│  [Camera on Mast] → [Pi 5 below deck] → [4G Hotspot]          │
│   Wide angle view     Auto-start        Mobile data           │
│                                                                │
│                          ↓                                     │
│                                                                │
│                    [Internet]                                  │
│                                                                │
│                          ↓                                     │
│                                                                │
│            [Friend's Phone Anywhere]                           │
│             Watches live stream                                │
│                                                                │
└────────────────────────────────────────────────────────────────┘

RECOMMENDED SETTINGS:
- Resolution: 1280×720 (saves mobile data)
- FPS: 15 (smooth enough, less data)
- Upload to server: Every 10 seconds (redundancy)
- Auto-start on boot (always recording)

POWER:
- Pi 5: ~5-8W
- With 12V → 5V converter
- Can run on boat battery all day

═══════════════════════════════════════════════════════════════════════════
                          TROUBLESHOOTING FLOWCHART
═══════════════════════════════════════════════════════════════════════════

Camera Not Working?
    │
    ├─→ Check cable connection
    │   └─→ Reseat CSI cable on both ends
    │
    ├─→ Check if camera enabled
    │   └─→ sudo raspi-config → Interface → Camera
    │
    └─→ Test with libcamera
        └─→ libcamera-hello

Can't Access Stream?
    │
    ├─→ Check Pi IP
    │   └─→ hostname -I
    │
    ├─→ Check firewall
    │   └─→ sudo ufw allow 8080
    │
    └─→ Check same network
        └─→ Ping Pi from phone

Stream Freezing?
    │
    ├─→ Lower resolution
    │   └─→ CAMERA_RESOLUTION = (1280, 720)
    │
    ├─→ Lower FPS
    │   └─→ CAMERA_FRAMERATE = 15
    │
    └─→ Reduce quality
        └─→ JPEG_QUALITY = 70
