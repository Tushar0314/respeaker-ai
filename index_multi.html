📌 How to Add More Cameras

To add additional cameras:
1. Connect camera to Raspberry Pi
2. Run: python camera_stream_multi.py --camera 2 --port 8082
3. Start SSH tunnel: ssh -R 8082:localhost:8082 bhaven@164.92.89.157 -N
4. Refresh this page to see the new camera
