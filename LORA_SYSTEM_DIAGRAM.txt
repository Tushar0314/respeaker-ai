                    COMPLETE DATA FLOW EXAMPLE
═══════════════════════════════════════════════════════════════════════

SCENARIO: Friend sends waypoint → Pi5 transmits → LoRa32 receives →
          User sends command → Pi5 speaks

Step 1: Friend App → Pi5
  ┌──────────────┐
  │  Friend App  │
  │ (Phone/Watch)│
  └──────┬───────┘
         │ WiFi/BLE
         ▼
  waypoints.json updated:
  {
    "waypoints": [
      {"name": "WP1", "lat": 37.788250, "lon": -122.432400}
    ]
  }

Step 2: Pi5 Transmits (lora_transmitter.py)
  
  Reads: waypoints.json
  Formats: "WP1:37.788250,-122.432400"
  Sends: Serial → LoRa Module → Radio

Step 3: LoRa32 Receives (lora32_example.ino)
  
  Receives: "WP1:37.788250,-122.432400"
  Parses: name=WP1, lat=37.788250, lon=-122.432400
  Displays: Serial Monitor / OLED
  
  Output:
  ┌─────────────────────────────────────┐
  │  RECEIVED FROM PI5                  │
  │  WP1: 37.788250, -122.432400       │
  │  RSSI: -45 dBm, SNR: 9.5 dB        │
  └─────────────────────────────────────┘

Step 4: User Presses Button on LoRa32
  
  Button → sendCommand("hold")
  Sends: "hold" → LoRa Radio

Step 5: Pi5 Receives & Speaks (lora_receiver_tts.py)
  
  Receives: "hold"
  Parses: Simple text format
  Calls: espeak -v en -s 150 -p 50 "hold"
  
  Output:
  [RX] Received: hold
  [Format] SIMPLE
  [Text] hold
  🔊 SPEAKING: "hold"
  
  Speaker: 🔊 "hold"
