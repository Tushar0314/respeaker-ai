                              SYSTEM ARCHITECTURE

┌───────────────────┐
│   Friend's Phone  │  📱 React Native App
│  (React Native)   │  - Tap map to add waypoints
│                   │  - Send Waypoints button
└─────────┬─────────┘  - Encodes: WP1:lat,lon;WP2:lat,lon
          │
          │ BLE (Bluetooth Low Energy)
          │ UUID: 12345678-1234-1234-1234-1234567890ab
          │ Data: Base64 encoded waypoint string
          ▼
┌───────────────────┐
│   ESP32 Device    │  📡 BLE Receiver
│   (LoRa/BLE)      │  - Receives from phone
│                   │  - Forwards to Raspberry Pi
└─────────┬─────────┘  - Via Serial/WiFi
          │
          │ Serial: /dev/ttyUSB0 (USB cable)
          │    OR
          │ WiFi: HTTP/MQTT
          │ Format: WP1:37.7749,-122.4194;WP2:...
          ▼
┌───────────────────┐
│  Raspberry Pi     │  🥧 Data Processor
│                   │
│  ┌─────────────┐  │  📥 waypoint_receiver.py
│  │  Receiver   │  │  - Listens on serial/network
│  │   Script    │  │  - Parses waypoint data
│  └──────┬──────┘  │  - Decodes Base64
│         │         │  - Calculates distances
│         ▼         │
│  ┌─────────────┐  │  💾 JSON Files
│  │waypoints.json│  │  - Stores all waypoints
│  │current_loc  │  │  - Current position
│  │  .json      │  │
│  └──────┬──────┘  │
│         │         │
│         ▼         │
│  ┌─────────────┐  │  🎤 Voice Assistant
│  │   Voice     │  │  - Listens: "Where am I?"
│  │  Assistant  │  │  - Reads waypoint data
│  └──────┬──────┘  │  - Calculates distance
│         │         │  - Speaks location
│         ▼         │
│     [Speaker]     │  🔊 Audio Output
└───────────────────┘  "You are at waypoint WP1"

1️⃣  FRIEND CREATES ROUTE ON PHONE
    ┌──────────────────────────────────────┐

    Raw: WP1:37.7749,-122.4194;WP2:37.7750,-122.4195;WP3:37.7751,-122.4196
    Base64: V1AxOjM3Ljc3NDksLTEyMi40MTk0O1dQMjozNy43NzUwLC0xMjIuNDE5...

3️⃣  ESP32 RECEIVES & FORWARDS
    Serial Output → /dev/ttyUSB0
    
4️⃣  RASPBERRY PI PROCESSES
    waypoint_receiver.py:
    - Decodes Base64
    - Parses waypoints
    - Saves to waypoints.json
    - Updates current_location.json

5️⃣  YOU ASK LOCATION
    🗣️ "Where am I?"

6️⃣  VOICE ASSISTANT RESPONDS
    🔊 "You are at waypoint WP1. You have 3 waypoints in your route."

PROBLEM: "I cannot find the location right now"
    │
    ├─→ Check: waypoints.json exists?
    │   └─→ NO → Run: python3 waypoint_receiver.py test
    │
    ├─→ Check: current_location.json exists?
    │   └─→ NO → Run: python3 waypoint_receiver.py test
    │
    └─→ Check: JSON files valid?
        └─→ NO → Delete and recreate with receiver

PROBLEM: Waypoint receiver not receiving data
    │
    ├─→ Check: ESP32 connected?
    │   └─→ NO → Connect USB cable, check ls /dev/tty*
    │
    ├─→ Check: Correct serial port?
    │   └─→ NO → Try /dev/ttyUSB0, /dev/ttyACM0, /dev/serial0
    │
    └─→ Check: React Native app sending?
        └─→ NO → Tap "Send Waypoints" button

PROBLEM: Voice assistant not responding
    │
    ├─→ Check: ReSpeaker detected?
    │   └─→ NO → Run: arecord -l
    │
    ├─→ Check: Speaking loud enough?
    │   └─→ NO → Speak closer to microphone
    │
    └─→ Check: Vosk model installed?
        └─→ NO → Check models/en/ folder exists
